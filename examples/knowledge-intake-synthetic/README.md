# Knowledge Intake Synthetic Example

This public-safe example demonstrates the Atlas Knowledge Intake boundary with synthetic source material.

It proves:

- source identity
- version/status
- knowledge unit to source linkage
- citation/provenance
- retrieval evidence
- issue/conflict
- human-review signal

It does not include private documents, company knowledge, embeddings, vector databases, prompts, or LLM calls.

Run:

```bash
python examples/knowledge-intake-synthetic/run_example.py
```
