# AI Execution Synthetic Example

This public-safe example demonstrates the Atlas AI Execution boundary with a synthetic provider adapter.

It proves:

- synthetic request
- synthetic provider adapter
- success and failure normalization
- fallback signal
- confidence/risk extraction
- human escalation
- `AIExecutionResult`

It does not call an external AI API.

Run:

```bash
python examples/ai-execution-synthetic/run_example.py
```
